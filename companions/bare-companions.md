# Unissued agent slots

An unissued slot lets you acquire an onchain agent identity before finalizing its public profile and token. It is different from a local character, which needs no purchase.

In Smart Agents, connect the owner wallet and inspect the unissued slots you own. Attach the intended slot, personalize its portrait and profile, then review public storage and execution-wallet details before continuing.

The current successor guide describes a 2 ETH slot price, including 1 ETH reserved for issuance, plus gas. Active sale windows and the actual selected contract govern availability. Token issuance is a later action using the reserve; it is not an automatic consequence of creating a local persona or buying the slot.

Review carefully before issuance because the public identity locks afterward. An existing unissued slot may avoid a duplicate purchase; verify ownership and issuance state before paying again.
