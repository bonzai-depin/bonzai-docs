# Install BonzAI+

BonzAI+ is the browser assistant for page chat, text/image capture, Live video understanding, Imagine and dataset preparation. The current BonzAI Web welcome panel marks extension installation **Coming Soon**; it does not provide a public store-install button.

Check the official [BonzAI website](https://bonzai.sh) for distribution availability. Do not install an unofficial extension that claims to be BonzAI+. If you are working from an authorized development build, follow that repository’s extension setup instructions.

Once an official compatible build is installed, open its browser side panel and follow model setup. Model files need storage and a compatible browser. Page capture, microphone or other permissions should be granted only for the workflow you intend to use.

You can start now with [BonzAI Web](../products/bonzai-web.md) for local text chat or [Desktop](install-desktop.md) for the complete studio.
