# What’s new in BonzAI

Updated 24 October 2026 against the current Web and Desktop source. **4.1.0** is the downloadable Desktop release. The source checkout also contains ongoing work; use this page as an orientation to the current product, not a promise that every newer screen exists in an older installation. Availability of online services and contracts is separate from the app version.

## A clearer route into the studio

Web now links directly to four 4.1.0 installers, labels Linux CUDA and ROCm separately, and provides matching SHA-256 files. The [installation guide](install-desktop.md) explains which package to choose.

## More ways to make the workspace comfortable

The theme collection now includes Tokyo Night, Catppuccin Mocha, Gruvbox, Nord, Dracula, Rosé Pine, Everforest, Kanagawa, Solarized Dark, Monokai, Petal Silk, Tea Garden, Rice Paper, Solarized Light, Catppuccin Latte, Lantern Glow, Deep Current and Gilded Ink. Web provides the same new palettes, a searchable gallery and light/dark filtering. Existing choices remain available.

[Choose a theme](../desktop/themes.md).

## Agents and workflows are easier to find

The current Desktop workspace brings Roleplay into creation navigation and uses Smart Workflows to organize repeatable work. Local agents can participate without minting an NFT. Teams keep their mission, tasks, tools, activity and deliverables together. Activity tracking helps you return to work while moving between views; details can vary by installed version.

Try a bounded task such as producing a short narration with artwork, or preparing a customer quote for review. [Roleplay](../desktop/roleplay.md) · [Smart Workflows](../desktop/company-jobs.md).

## Build worlds from reusable pieces

World Forge connects object and level generation with game assembly and playtesting. Save a useful object once, then reuse it in a level. Local creation and playtesting are separate from optional publication.

[World Forge](../desktop/world-forge.md).

## The Web3 guide is available outside the app

The [public Web3 Guide](../web3/guide.md) covers all 15 activities in Desktop’s guide, including public storage, content minting, staking, reward claims, token issuance, trading fees, remote jobs and provider limitations. It explains what you get, what you pay, and when a feature depends on deployment or configuration.

## If you remember older token rules

You do not need a token balance for local Web chat or Desktop generation in the current source. Local Smart Workflows are free. Remote jobs, public uploads, minting, staking and market transactions are separate actions. Older descriptions of a five-message Web limit, zero-fee agent pools, or automatic provider income should not be used to predict the current flow. Check the selected contract and the actual quote in the application.
