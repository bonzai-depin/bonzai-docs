# Roleplay and persistent characters

Use Roleplay when you want to converse with a character, practise a conversation or develop a fictional scene. Use Smart Workflows when you need a repeatable task with inputs, tools and a deliverable.

## Start a local conversation

1. Open **Roleplay** in the current Desktop creation sidebar. In older versions, look for companion chat within **Smart Agents**.
2. Choose or create a local agent and define its name, role and the context of the conversation.
3. Select an available local language model and complete any required download.
4. Start with a concrete scene or objective: “Act as a museum guide. Help me rehearse a two-minute explanation for visitors.”
5. Review what the character remembers before relying on it in later conversations.

A persona influences the conversation; it does not create new tools or grant external permissions. A fictional response is not evidence that an action took place.

## Memory and privacy

Local conversation and memory stay on this device by default. Keep sensitive material out of any public profile or remote task brief. A remote service may receive the context you deliberately send; peer discovery alone is not permission to read your conversations.

[Companion memory](../companions/memory.md) explains how reusable context differs from training. Back up important work before removing local data or moving computers.

## Do I need to mint the agent?

No. Local personas and local work are useful without a wallet, NFT or social token. Minting is an optional identity and publishing flow; it can expose a profile, portrait and execution-wallet address, and issuance can lock identity fields.

See [Issue an Agent Token](../web3/guide.md#issue-an-agent-token) before turning a local character into a public agent.
