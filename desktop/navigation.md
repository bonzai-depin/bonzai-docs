# Find your way around Desktop

Start in **Create** for a single result. Move to **Automate** when you want an agent or team to repeat a process. Wallet and network controls are separate from local creation.

| Area | Views | Use it for |
| --- | --- | --- |
| Create | Chat, Image, Audio, Video, 3D, Roleplay | Write, generate media, build worlds and talk to characters |
| Earn | Ownership, Markets, Rewards | Explore optional publication, tokens, staking and claims |
| Automate | Smart Agents, Smart Workflows; jobs when enabled | Configure agents and organize tasks around a result |
| Train | Tune, Uncensor and dataset-related flows | Prepare data and transform supported models |
| Help | Memory, Benchmark, Harness, Licenses | Inspect context, performance, tools and model terms |
| Settings | Language and theme controls | Personalize the workspace |

Labels and available views can differ by version and enabled integrations. [What’s new](../getting-started/whats-new.md) distinguishes the current source from release availability.

## Models, generation and activity

Choose the model inside the tool you are using. Wait for its download and loading state to finish before generation. The current Desktop shell includes an activity bar for local services and running work; use it to return to the relevant view. Switching views is not the same as stopping a task, and closing Desktop is not a cloud deployment.

## Inside Smart Workflows

Choose a team, then use its mission, backlog, chat, activity, tools and deliverables to understand what it is doing. Business templates expose relevant operations: for example, a maintenance team may have Today, Schedule, Work orders, Clients and Inbox. Team settings configure agents and execution; operations settings configure the business process.

## Network and ownership

The network control opens Private, Consumer and Provider modes and related settings. Discovery never grants access to all your local data. Connect opens supported wallet/account choices, and signing a transaction is a separate action.

Use the in-app **Web3 Guide**, or read the same [activity walkthroughs in the docs](../web3/guide.md), before publishing, staking or paying for remote work.
